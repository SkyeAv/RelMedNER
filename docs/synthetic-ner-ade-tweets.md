# Synthetic ADE tweets

The one locally-built synthetic corpus: `anthonyyazdaniml/synthetic-ner-ade-tweets-v1`
(MIT), two hub zips of BRAT standoff pairs built out-of-band into the package data dir
and declared as a gold `script` ingest (17,000 rows) plus a `fullmap` ingest over the
8,502 unannotated texts.

Both artifacts (`ade_tweets.avro` and `ade_tweets_unannotated.tsv`) are operator-built and
stay out of git, like `interventions.avro`: a fresh clone has neither file and the stream
fails with `FileNotFoundError` rather than yielding nothing. They live on wenceslaus at
`/local_raid1/sgoetz/operator-data/synthetic-ner-ade-tweets/`, and the remote gate stages
them into the package data dir before the suite runs.

Dataset-format notes (`SyntheticNerAdeTweetsScript`, local datasets `synthetic-ner-ade-tweets/ade_tweets.avro` and `synthetic-ner-ade-tweets/ade_tweets_unannotated.tsv`): the corpus is anthonyyazdaniml/synthetic-ner-ade-tweets-v1 (MIT), two hub zips of BRAT standoff pairs (text + .ann) built out-of-band into the package data dir (avro md5 8f1e8e2cf105bbedeec0fdb9035f3fe1, tsv md5 403d767f654c856b66ba84a761649072); 17,000 tweets (train 15,300, val 1,700; 8,500 ADE-mentioning + 8,500 ADE-free, matching the hub card); 10,341 T-lines carry the single raw label `ADE` with char offsets END-EXCLUSIVE (10,341/10,341 slice-verified) and zero malformed, out-of-bounds, discontinuous, or containment defects; 8,502 docs ship an empty .ann (all 8,500 negatives plus pos_5808 and pos_341) and pass through as text-only rows, which the avro entry's declared-outputs filter drops; the N-line MedDRA LLT notes are never read (provenance is neither shipped nor used); `ade` resolves through the shared chain with `DiseaseOrPhenotypicFeature` as the generic fallback tier while the fullmap entry supplies specific classes; the fullmap entry covers only the 8,502 unannotated texts because the pipeline's default NEAR dedup exact-collapses identical texts (mining the gold tweets too would arbitrarily discard one copy), so positives stay gold-only; 23 zip members were latin-1 encoded and are decoded with a utf-8-strict + latin-1 fallback. Measured on wenceslaus, 2026-09-22, this branch: full-file script dispatch (`remote-gate.sh probe -- --declared 'synthetic-ner-ade-tweets/ade_tweets.avro' --limit 17000 --script SyntheticNerAdeTweetsScript --outputs entities`, no `--text-column`: a local avro entry projects no columns) emitted 8,498/17,000 rows (50.0%; shapes entities=8,498 plus relations=11 as free signal; 10,341 mentions, 11 relations); full-split fullmap probe (`remote-gate.sh probe -- --declared 'synthetic-ner-ade-tweets/ade_tweets_unannotated.tsv' --limit 9000 --text-column text --fullmap`) rows_in=8,502 rows_out=8,502, 19,985 mentions (2.35/doc), 1,136 relations, 8,384 docs with mentions.
